# 02: 登录拉起时不打扰（最小化、不抢焦点）

**What to build:** 应用被启动条目拉起时（命令行含 `--autostart`），窗口以最小化出现在任务栏、不抢焦点、不弹任何提示。没有该参数时行为与今天完全一致。服务器不可达时切出的配置页同样以最小化出现——否则登录瞬间会凭空弹出一个用户没预期的窗口。用户从任务栏恢复窗口时，看到的仍是上次记录的尺寸与最大化状态。

**Blocked by:** 01 — 「随系统启动」开关（写入、回显与外部禁用）

**Status:** ready-for-agent

- [ ] 命令行中的 `--autostart` 由主进程最早阶段解析为纯函数，与其它参数共存时不误判
- [ ] 带 `--autostart` 启动时，首个窗口 `isMinimized()` 为真且不是当前聚焦窗口
- [ ] 不带该参数启动时，窗口正常显示并聚焦，行为与改动前一致
- [ ] 带 `--autostart` 且服务器不可达时，切出的配置页同样最小化
- [ ] 从任务栏恢复后，窗口尺寸与最大化状态与上次关闭时记录的一致（含"上次是最大化"的情形）
- [ ] 该行为与平台无关，可在 Linux e2e 环境验证；e2e 复用现有启动 helper，只增加"追加参数"能力
- [ ] 关闭窗口仍然立即退出进程，不因最小化启动而改变生命周期
