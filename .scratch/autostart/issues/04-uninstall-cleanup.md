# 04: 卸载时清理启动条目

**What to build:** 通过 Inno 安装版卸载后，启动条目随之消失——用户不会在下次登录时遇到"找不到程序"的系统错误框。条目本来就不存在时静默跳过。卸载时"是否同时删除服务器地址、登录状态和本地设置"的既有询问与行为保持不变。

**Blocked by:** 01 — 「随系统启动」开关（写入、回显与外部禁用）

**Status:** ready-for-agent

- [ ] 卸载流程按与运行时相同的值名删除当前用户的启动值
- [ ] 条目不存在时卸载不报错、不弹窗
- [ ] 从未勾选过该开关的用户卸载后系统状态无变化
- [ ] 卸载时删除用户数据的选择行为与文案不变
- [ ] 安装器脚本中值名与运行时模块使用同一个字符串，并有注释指明两处必须一致
- [ ] 本地消息文件校验用例仍然通过（安装器只允许引用仓库内存在的语言文件）
