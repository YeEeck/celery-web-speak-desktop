# 03: 移动目录后自愈启动条目

**What to build:** 便携版被解压到新目录、或安装版换了安装位置之后，下次启动应用时启动条目指向的路径被改写成当前可执行文件，用户不需要回菜单重新勾选。只有在"条目存在且处于启用状态、且记录的路径与当前可执行文件不一致"时才写；条目不存在、未启用、或路径已经正确时一律不写。

**Blocked by:** 01 — 「随系统启动」开关（写入、回显与外部禁用）

**Status:** ready-for-agent

- [ ] 条目启用但路径指向旧位置时，启动后条目路径变为当前可执行文件，参数保持不变
- [ ] 条目未启用（被外部禁用）时，启动过程不产生任何写入
- [ ] 条目不存在时，启动过程不创建条目
- [ ] 记录路径已与当前可执行文件一致时，启动过程不产生任何写入
- [ ] 自愈发生时留下一条本地日志事件；失败不影响应用启动
- [ ] 上述四种情形由伪后端单测覆盖，断言"写了什么/没写什么"而非内部调用顺序
