# 04 — 端到端验收与限制说明

**What to build:** 两仓合体后的端到端验收与用户文档收尾。在 Windows 与 Linux X11 实机验证完整链路：设置"语音浮层"页配置大小/位置/不透明度 → 开启浮层 → 进入语音 → 游戏画面（窗口化/无边框全屏场景）上浮层按配置渲染（位置、大小、说话/未说话不透明度）并实时反映状态 → 退出语音回到空态 → 关闭开关浮层消失；同时验证浮层不影响主窗口、不抢焦点、鼠标穿透。文档与用户可见说明明确限制：Windows 独占全屏与 Linux Wayland 下浮层不可见、OBS 等录制软件的游戏源捕获不到浮层、浮层页面依赖 Web 服务在线。README 增补浮层配置入口、限制说明与新旧版本兼容矩阵。
